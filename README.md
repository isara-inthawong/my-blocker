# my-blocker
My Browser Extension


## ความแตกต่างหลักระหว่าง disabled_auto_hosts และ disabled_auto_selectors ในระบบ Block/Hide Element นี้ คือระดับการทำงานและขอบเขตของการปิดกั้นฟีเจอร์อัตโนมัติ ดังนี้ครับ:
- disabled_auto_hosts (ระดับเว็บไซต์/Hostname)
    * หน้าที่: ใช้เก็บรายชื่อโดเมนเว็บไซต์ (เช่น example.com) ที่ผู้ใช้ต้องการ "ปิดการทำงานอัตโนมัติทั้งหมด" บนเว็บไซต์นั้น ๆ
    * พฤติกรรม: หากเว็บไซต์ใดมีชื่ออยู่ในลิสต์นี้ ฟีเจอร์การตรวจจับโฆษณาอัตโนมัติ (autoDetectAndHideAds) และกฎสำเร็จรูป (DEFAULT_AUTO_PICK_RULES) จะไม่ทำงานบนเว็บไซต์นั้นเลย แต่ผู้ใช้ยังคงสามารถซ่อน Element แบบ manual (กดเลือกเองผ่าน Picker) ได้ปกติ

- disabled_auto_selectors (ระดับ Element / รายตัว)
    * หน้าที่: ใช้เก็บรายชื่อ CSS Selector เฉพาะเจาะจงที่ระบบเคยตรวจจับให้อัตโนมัติ แต่ถูกผู้ใช้ "กดลบออก" จากหน้าจัดการ
    * พฤติกรรม: ป้องกันไม่ให้ระบบอัตโนมัติวิ่งกลับมาซ่อน Element เดิมซ้ำอีกในอนาคต (แม้ว่าหน้าเว็บจะรีเฟรชหรือโค้ดอัตโนมัติพยายามตรวจจับเจออีกรอบ ก็จะถูกข้ามไปเพราะมีชื่ออยู่ในลิสต์นี้)
